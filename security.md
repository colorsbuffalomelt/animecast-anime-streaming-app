## 🍿 A Cinematic Streaming Experience

**Animecast** is a next-generation, open-source anime streaming application built for mobile devices. Unlike cluttered web players, Animecast offers a native, fluid, and distraction-free experience. Built with Flutter, it delivers buttery-smooth 60FPS animations, zero ads, and a stunning dark-mode interface that puts the artwork front and center.

It aggregates content from multiple sources to ensure high availability, fetching the highest quality video streams (up to 1080p) while maintaining a rich, searchable database of metadata, including synopses, genres, and episode lists. Sync your watch history across devices and pick up exactly where you left off.

> 💡 **Why Animecast?** Because watching anime should feel like a premium cinema experience, not a fight against pop-up ads. Download the app, pick a show, and press play.

## ⚙️ Architecture Overview

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 📱 **Frontend** | Native UI, animations, and state management | `Flutter` + `Riverpod` |
| 🎬 **Video Player** | HLS streaming, subtitle rendering, hardware decoding | `Better Player` |
| 🌐 **Backend API** | Scraping, metadata aggregation, and proxy | `Node.js` + `Express` |
| 🗄️ **Database** | User accounts, watch history, and favorites | `Firebase` |

</div>

The app is built using Clean Architecture principles. The UI layer is completely decoupled from the data layer, making it incredibly easy to swap out the backend API or add new streaming sources without touching the frontend code.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is Animecast available on the App Store or Google Play?</b></summary>

Due to the nature of the content aggregated, the app is distributed as a direct APK download for Android and via TestFlight for iOS. It is not available on official app stores.
</details>

<details>
<summary><b>Does the app support offline viewing?</b></summary>

Yes! Premium users (or self-hosters) can download episodes directly to their device storage. The app manages the downloads and allows you to watch them in airplane mode.
</details>

<details>
<summary><b>How does the app handle updates?</b></summary>

The app features an in-app updater. When a new version is released, a banner will appear prompting you to download the latest APK directly from within the app.
</details>

<details>
<summary><b>Can I contribute to the development?</b></summary>

Absolutely. We are always looking for Flutter developers. Check the `CONTRIBUTING.md` file in the repository to get started with local development.
</details>

<details>
<summary><b>How do I report a broken video source?</b></summary>

If a specific episode fails to load, use the in-app "Report Source" button. It automatically logs the episode ID and notifies the backend team to update the scraper.
</details>
